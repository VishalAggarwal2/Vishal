### Editor & IDE

- My editor of choice is [IntelliJ IDEA](https://www.jetbrains.com/idea/) for Java/Spring Boot work
- [Visual Studio Code](https://code.visualstudio.com/) for JavaScript, TypeScript, and everything else
- Theme: [One Dark Pro](https://marketplace.visualstudio.com/items?itemName=zhuangtongfa.Material-theme)

### Terminal

- [iTerm2](https://iterm2.com/) on macOS with [oh-my-zsh](https://ohmyz.sh/)
- [tmux](https://github.com/tmux/tmux) for session management on remote servers

### Languages & Frameworks

- **Java** with **Spring Boot** for backend services and microservices
- **Node.js** with **Express.js** for REST APIs and MERN stack projects
- **React** for frontend development
- **Python** for scripting and automation
- **SQL** (PostgreSQL, MySQL) for relational data

### DevOps & Cloud

- **Docker** for containerisation and consistent dev/prod environments
- **Jenkins** and **ArgoCD** for CI/CD pipelines
- **AWS** (EC2, S3, IAM) for cloud deployments
- **Linux / Bash** for scripting and server management

### Monitoring & Observability

- **Prometheus** for metrics collection
- **Grafana** for dashboards and alerting
- **Winston** and **Morgan** for application logging in Node.js
- **PM2** for Node.js process management in production

### Desktop Apps

- [Postman](https://www.postman.com/) for API development and testing
- [Brave](https://brave.com/) as my main browser
- [Slack](https://slack.com/) and [Discord](https://discord.com/) for team communication
- [Notion](https://www.notion.so/) for notes and documentation
- [Spotify](https://www.spotify.com/) for focus music

### Version Control & Collaboration

- **Git** and **GitHub** for version control
- **GitHub Actions** for lightweight CI workflows
- [Jira](https://www.atlassian.com/software/jira) for issue tracking

### Desk Setup

- **Laptop**: MacBook (primary machine)
- **Keyboard**: Mechanical keyboard for those long coding sessions
- **Monitor**: External monitor for extra screen real estate
