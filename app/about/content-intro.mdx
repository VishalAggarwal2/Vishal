# About Me

I combine deep full-stack and DevOps skills with a product mindset to define the right problems, build the right solutions, and ship software that creates measurable impact.

Currently pursuing my **B.Tech in Computer Science & Engineering** at **The LNM Institute of Information Technology (LNMIIT)**, graduating in 2026.

- **DevOps & CI/CD**: Architect end-to-end pipelines with **Jenkins** and **ArgoCD** for automated build, test, and deployment workflows that eliminate manual release steps.
- **Containerisation**: Package and orchestrate services using **Docker**, ensuring consistent environments from dev to production.
- **Observability**: Set up monitoring and alerting stacks with **Prometheus** and **Grafana**, cutting system downtime and giving teams real-time insight into production health.
- **Full Stack**: Build full-featured web applications with the **MERN stack** (MongoDB, Express, React, Node.js), including JWT authentication, RBAC, and reusable component libraries.
